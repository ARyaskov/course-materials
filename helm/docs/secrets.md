# Секреты Tessera

Значений здесь нет — только перечень того, что нужно, и где это взять.

| Ключ | Что защищает | Где взять | Ротация |
| --- | --- | --- | --- |
| `TESSERA_DATABASE_DSN` | Полный доступ к заказам и билетам | Менеджер паролей, `tessera/<env>/db-dsn` | Квартал |
| `TESSERA_REDIS_PASSWORD` | Копия броней в Redis | Там же | Квартал |
| `TESSERA_TICKET_SIGN_KEY` | Подпись кода билета: утечка = подделка билетов | Там же | Месяц |

## Как секрет попадает в кластер

| Окружение | Механизм |
| --- | --- |
| dev | Создаётся чартом из `envs/values-dev.yaml`; значения заведомо не боевые |
| staging | SOPS + `helm-secrets`, файл `envs/secrets-staging.enc.yaml` |
| production | External Secrets Operator, объект `ExternalSecret` |

Чарт во всех случаях кроме dev ссылается на существующий Secret через
`secrets.existingSecret` и сам ничего не создаёт.

## Ротация ключа подписи билетов

`TESSERA_TICKET_SIGN_KEY` передаётся переменной окружения и читается один раз
при запуске. После обновления Secret перезапустите API и worker:

```bash
kubectl rollout restart deployment/tessera-api deployment/tessera-worker -n <ns>
kubectl rollout status deployment/tessera-api -n <ns>
```

Учебная реализация поддерживает один ключ: билеты, выпущенные старым ключом,
после ротации перестанут проходить проверку подписи. На стенде сначала завершите
сценарии со старыми билетами. Для ротации без потери действующих билетов нужно
добавить набор ключей проверки и идентификатор ключа; этого в проекте пока нет.

Оплата в учебном API имитируется эндпоинтом `/api/v1/orders/{id}/pay`.
Платёжный провайдер и его вебхуки не подключены.

## Если секрет утёк

1. Считать значение скомпрометированным навсегда: удаление из git не помогает.
2. Сменить значение в источнике (база, провайдер, сгенерировать новый ключ).
3. Обновить Secret во всех окружениях, включая staging.
4. Перезапустить всё, что подключало значение переменной окружения.
5. Проверить, где ещё лежали копии: локальные `.env`, переменные CI, документация.
6. Оценить последствия по таблице выше.
