# Team guide Atrium (урок 16.3)

Дополняет официальный Kotlin coding conventions (форматирование — ktlint, спор решает `ktlintFormat`). Каждое правило — с «почему» и способом проверки.

## Nullability
- Nullable только на границах (репозитории `find(): T?`, внешние API, парсинг); внутри домена `null` не путешествует. *Почему:* контекст для решения есть у вызывающего. *Проверка:* ревью.
- `!!` — только с комментарием-обоснованием и `@Suppress("UnsafeCallOnNullableType")`. *Проверка:* detekt.
- `lateinit` — тесты и `@SpringBootTest`; в production — конструктор. *Проверка:* ревью.
- `Optional` разворачивается на границе в `T?`. *Проверка:* detekt `ForbiddenImport` в domain/application.

## Extension-функции и классы
- Extension — если выражается через публичный API приёмника и читается как метод; переходы состояния сущности — методы класса. *Почему:* инварианты живут в классе.
- Файл extension над чужим типом — `<Type>Extensions.kt` в пакете использования; общего `Utils.kt` нет.
- `data class` — значения (DTO, команды, события, результаты); сущности с id — `class` с equals по id, переходы методами, без `copy`. *Проверка:* detekt `DataClassEntity`.
- sealed — закрытые множества с `when`; enum — варианты без данных; value class — идентификаторы и единицы.

## Корутины
- Scope — `ApplicationScope`; `GlobalScope` запрещён; `CoroutineScope(...)` в классе только с `AutoCloseable`. *Проверка:* detekt `GlobalCoroutineUsage`.
- Dispatcher — зависимость конструктора; `Dispatchers.IO` в теле класса — ошибка ревью.
- `suspend` только при реальной приостановке. `runBlocking` — `main`, тесты, `*Blocking`-адаптеры. *Проверка:* detekt `RunBlockingInProduction`.
- `catch (e: Exception)` без проброса `CancellationException` — ошибка; используйте `runCatchingCancellable`. *Проверка:* detekt `SwallowedCancellation`.

## Ошибки и результаты
- Ожидаемый отказ — вариант sealed-результата; инфраструктура и нарушения инвариантов — исключения (`AtriumException` с `errorId`).
- Критерий: обрабатывается `when`-веткой → sealed; единственная реакция — откат и 5xx → исключение.
- `Result<T>` — не в публичных сигнатурах.

## Файл и имена
- Один публичный класс на файл (исключения: sealed-иерархия, связанные DTO). Порядок: свойства, `init`, публичные, приватные, `companion`.
- Пакеты по функциональности, модули по слоям. Use case — глагол+существительное; порт — существительное; реализация — префикс технологии.
- Булевы свойства без `is`; `find`/`OrNull` возвращают `null`, `get`/`require` бросают.
- Комментарии — «почему»; KDoc — на публичных API модулей и портах.
