# Время старта (урок 15.5)

Медиана из пяти запусков, ноутбук 4 ядра, JDK 25. В контейнере с 1 CPU — в 2–3 раза дольше.

| Вариант | app-spring | app-ktor | RSS | Прогрев |
| --- | --- | --- | --- | --- |
| JIT | 4,8 с | 1,6 с | 420 МБ | 30–60 с |
| layered jar + CDS (Dockerfile) | 3,1 с | 1,0 с | 400 МБ | 30–60 с |
| + AOT-кэш JDK 25 (`Dockerfile.spring.aot`, опция) | 2,2 с | 0,8 с | 380 МБ | 5–10 с |
| GraalVM native (не используется) | 0,15 с | 0,05 с | 180 МБ | нет |

Проверка архива: `JAVA_TOOL_OPTIONS="-Xshare:on -Xlog:cds"` — строгий режим падает, если архив не применим.
