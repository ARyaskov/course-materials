# Предметная область

Depot — сеть пунктов проката профессионального съёмочного оборудования.
Клиент бронирует конкретный экземпляр на интервал времени, забирает его
в точке выдачи и возвращает туда же.

## Сущности

| Сущность | Что описывает | Ключевые ограничения |
| --- | --- | --- |
| `Station` | точка выдачи | свой часовой пояс — от него зависит тариф |
| `EquipmentModel` | модель оборудования | суточная ставка, залог, стоимость замены |
| `Unit` | физический экземпляр | серийный номер уникален в пределах модели |
| `User` | клиент, оператор, администратор | адрес уникален без учёта регистра |
| `Booking` | бронь экземпляра на интервал | нет пересечений по экземпляру |
| `Rental` | факт выдачи и возврата | одна аренда на бронь |
| `DamageReport` | акт повреждения при возврате | привязан к аренде |
| `Invoice` | счёт по броне | не удаляется, только аннулируется |
| `RefreshSession` | сессия обновления токена | хранится хеш, не значение |

## Жизненный цикл брони

```
pending ──confirm──► confirmed ──return──► completed
   │                     │
   ├──cancel──► cancelled ◄──cancel──┘
   │
   └──hold expired──► expired
```

Из `cancelled`, `completed` и `expired` переходов нет. Таблица переходов
живёт в `domain/rules.py` и служит одновременно документацией и проверкой:
добавление статуса требует явного решения о переходах из него и в него.

Выдача не меняет статус брони. Она остаётся подтверждённой до возврата,
а факт выдачи хранится отдельной записью: это позволяет отличить
«оборудование у клиента» от «бронь оформлена».

## Правила, которые легко упустить

**Буфер на осмотр.** Между двумя арендами одного экземпляра нужно два
часа: осмотр, зарядка, чистка. Поэтому стык впритык — это конфликт,
хотя интервалы формально не пересекаются.

**Тариф по календарным суткам точки.** Аренда с 23:00 до 01:00 — двое
суток по тарифу, а не два часа. Сутки считаются в часовом поясе точки
выдачи, а не сервера и не клиента.

**Ставка фиксируется при бронировании.** Изменение цены модели не
меняет сумму уже оформленной брони.

**Удержание на час.** Неподтверждённая бронь держит экземпляр 60 минут,
затем освобождает его. Иначе достаточно оформить брони на весь парк
и не подтверждать их.

**Штраф за просрочку.** Одна двенадцатая суточной ставки за каждый
начатый час. Начисляется не более одного раза за календарные сутки —
это гарантирует уникальное ограничение на строку счёта, а не аккуратность
кода.

**Серьёзное повреждение выводит экземпляр из оборота.** Ущерб дороже
30% залога переводит единицу в ремонт: иначе она попадёт в следующую
бронь в тот же день.

## Что не делается

- Оплата внутри Depot: деньги проводит внешний шлюз, здесь хранится
  идентификатор удержания.
- Доставка: оборудование выдаётся и принимается только в точке.
- Продажа: списанный экземпляр получает статус и остаётся в истории.
