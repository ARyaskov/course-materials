# Тетради

`rotor_report.jl` — тетрадь Pluto: интерфейс к пакету для подбора параметров
прогона и просмотра результата.

Команды выполняются из папки `julia/` этого репозитория. Локальный Poincare
подключается через `[sources]` в `notebooks/Project.toml`:

```bash
julia --project=notebooks -e 'using Pkg; Pkg.instantiate()'
julia --project=notebooks -e 'using Pluto; Pluto.run(notebook = "notebooks/rotor_report.jl")'
```

Расчётной логики в тетрадях нет: всё, что они вызывают, находится в `src/`
и покрыто тестами. Тетрадь показывает результат и позволяет менять входные
данные, но не является источником истины.

Первый прогон выполняется при открытии. Для следующего выберите параметры
и нажмите «Выполнить прогон»: слайдеры сгруппированы через
`PlutoUI.confirm(PlutoUI.combine(...))`, поэтому их движение не запускает расчёт.
Результаты пишутся в `julia/results/`, который исключён из Git.
