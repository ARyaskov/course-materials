# Изменения

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии следуют [семантическому версионированию](https://semver.org/lang/ru/).

## 0.2.0 — 2026-09-06

### Несовместимые изменения

- `modal_analysis` определяет число мод жёсткого тела по краевым условиям,
  а не по относительному порогу для собственных значений. Для `bc = :cantilever`
  и `bc = :simple` результаты сдвинулись на одну моду: раньше первая упругая
  частота ошибочно отбрасывалась, и `result.f[1]` содержала вторую. Проверьте
  расчёты, использовавшие `modal_analysis` с закреплёнными краями.
- `adaptive_simpson` получила аргументы `maxdepth` и `maxevals`. При
  недостижимом допуске функция возвращает лучшее приближение с предупреждением
  вместо экспоненциального роста времени работы. Прежнее поведение — рекурсия
  до исчерпания стека — восстановить нельзя.
- `steady_temperature` для `BladeModel` использует собственный цикл
  установления с двойной буферизацией вместо интегрирования через `solve`.
  Результат совпадает в пределах допуска установления, сигнатура не изменилась,
  но промежуточные состояния больше не сохраняются.

### Добавлено

- Расчётный стенд: конфигурация `RunConfig` с проверкой схемы и хешем прогона,
  дисковый кэш этапов, пайплайн `run_pipeline`, отчёт в Markdown с проверкой
  допусков, командный интерфейс `main`.
- Оценка неопределённости: `ParameterSpace`, распределения параметров,
  `propagate` (Монте-Карло и последовательность Хальтона), `sobol_indices`,
  `delta_method`, `posterior_space`, `posterior_samples`.
- Скрипты `scripts/run.jl`, `scripts/collect.jl` и пример задания Slurm
  для параметрического прогона.
- Документация Documenter с проверяемыми примерами и справочником API.

### Исправлено

- `brent` и `bisect` не сходились из-за ошибки в разборе кортежа при обновлении
  границ интервала: выражение `(a, fa = m, fm)` присваивало `fa = m`, оставляя
  `a` неизменным, и метод возвращал `:maxiter` даже на простых функциях.
- Узлы металла, соседние с каналом охлаждения, классифицируются как `WALL`.
  Раньше обычный шаблон видел узел канала как узел с температурой охладителя
  и создавал сток тепла, не учтённый в балансе: невязка достигала 90 %.
- Индексы Соболя считаются по центрированному отклику. Без центрирования шум
  произведения `y_B · (y_AB − y_A)` на порядки превышал дисперсию отклика,
  и оценки выходили за пределы `[0, 1]`.
- `required_coolant_speed` использует относительный допуск `1e-3` вместо
  машинной точности: целевая функция вычисляется итерационно и точнее не бывает.

### Производительность

- Установление стационарного поля сечения лопатки ускорено примерно в 29 раз
  за счёт типовой стабильности, списков узлов по типам и слияния шага.

## 0.1.0 — 2026-06-15

Первый выпуск: численное ядро (сетки, конечные разности, квадратуры, решение
уравнений и систем, разреженная линейная алгебра), интерфейс моделей,
явные и адаптивные схемы Рунге — Кутты, предметные модели механики,
теплофизики и популяционной динамики, идентификация параметров и подготовка
данных для графиков.
